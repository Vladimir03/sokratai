## 2. Solution

Репетитор прикрепляет к варианту **один цельный аудиотрек** секции + **ручной транскрипт**. Ученик слушает трек во время экзамена (плеер над Частью 1); вопросы по треку — обычные задачи Части 1 (детерминированные чекеры уже работают). Транскрипт раскрывается **только после сдачи** — как разбор.

**Почему variant-level, а не per-task:** эталонный файл `delf-b2-tp-coll-exemple1-integral.mp3` (23:46, 21.7 МБ) — цельная запись всей секции с экзаменационными паузами (`integral`). Модель зеркалит `variant_pdf_url`.

### Scope

**IN (Релиз 1):**
- [P0] `listening_audio_url` + `listening_transcript` на `mock_exam_variants`; бакет `mock-exam-listening-audio`.
- [P0] Редактор варианта: upload аудио + self-check плеер + textarea транскрипта.
- [P0] Ученик: нативный `<audio controls>` над Частью 1 (sticky).
- [P0] Результат: collapsible «Аудирование» — переслушать + транскрипт (post-submit).
- [P0] Anti-leak: транскрипт = leak-класс `solution_text` (edge-selects + column-GRANT).

**OUT (сознательно):**
- Авто-транскрипция Whisper — v2 (24-мин трек не влезает в синхронный edge; нужна очередь + сегментация).
- Клик-по-слову / word-timestamps (VH-41 — отдельная фича).
- Ограничение числа прослушиваний (открытый вопрос Эмилии).
- Аудио в ДЗ и материалах занятий.
- Дробные баллы Ч1 (1,5 за вопрос) — **Релиз 2**, отдельный PR (`INT → NUMERIC`, трогает живой грейдинг физики).

## 4. Technical Design

| Слой | Файлы |
|---|---|
| Миграции | `20260731180000_mock_exam_listening_audio.sql` (колонки + бакет + обе RPC), `20260731190000_mock_exam_variants_column_grants.sql` (column-GRANT whitelist) |
| Edge | `mock-exam-tutor-api` (валидатор own-namespace, 4 хендлера, `GET /variants/:id/listening`, маркер `listening_fields_applied`), `mock-exam-student-api` (taking: аудио; result: аудио+транскрипт), `mock-exam-public` (invite: аудио) |
| Frontend | `TutorMockExamVariantEditor.tsx`, `StudentMockExam.tsx`, `StudentMockExamResult.tsx`, `mockExamApi.ts`, `studentMockExamApi.ts`, `useMockExamVariants.ts` |

**Ключевые архитектурные решения** (перф-критерии — план §3):
1. Аудио-байты **не идут через edge**: клиент → Storage напрямую, edge принимает только `storage://` ref. Снимает лимит Whisper 20/25 МБ и edge-таймаут 150 с.
2. `preload="metadata"` — открытие пробника не тянет 22 МБ.
3. Signed URL **12 ч** (`duration_minutes` до 600 мин) + `<audio onError>` → one-shot refetch.
4. `cacheControl: 86400` на upload — повторное прослушивание из кэша.

**Ops-пробы (пройдены до разработки):** Range через `api.sokratai.ru` → `206` + `content-range` (seek работает); POST 22 МБ проходит nginx (`client_max_body_size` не режет).

## Релиз 1.5 — «Блоки заданий» (2026-08-01)

**Повод.** Разбор реальных данных прода: в варианте Эмилии «DELF B1 junior» (29 задач, заведён 31.07) общая преамбула продублирована дословно в 6 задачах, вторая — в 5. Вариант — плоский список задач, общему материалу жить негде. Модель «один трек на вариант» (Релиз 1) покрывает только её `integral`-файл; у DELF каждый *exercice* — свой документ.

**Уточнение от Эмилии (TG, 01.08):** «А можно сделать чтобы было и так и так? И один файлом и несколько.» — модель блоков покрывает оба случая без ветвлений: блок без привязок = общий материал на всю работу.

### Решение

Сущность **«Блок»** = `{название, текст-инструкция, фото, аудио}` + N привязанных задач. Аудио — один из видов материала, а не отдельная механика. Привязка задаётся **из блока** чипами («exercice = вопросы 1–8»), на карточке задачи — read-only бейдж (один источник истины).

Гейт секции — `subjectRequiresCefr(subject) || blocks.length > 0`: только иностранные языки (решение владельца), но уже заведённые блоки не становятся недостижимыми при смене предмета.

### Схема

| Объект | Назначение | GRANT |
|---|---|---|
| `variants.task_blocks_json` | `[{id,title,instruction,image_url,audio_url}]` — условие | **есть** |
| `variants.block_transcripts_json` | `{blockId: текст}` — ответы аудирования | **нет, никогда** |
| `variants.content_revision` | CAS против stale-клиента | есть |
| `variant_tasks.block_id` | привязка, fail-closed `BLOCK_NOT_FOUND` | tutor-only таблица |

Миграции: `20260801100000`, `20260801100100`, `20260801120000`.

### AC

- **AC-7.** Репетитор-языковик заводит N блоков (≤10), у каждого — название, общий текст, документ, трек, транскрипт; вопросы привязываются чипами.
- **AC-8.** Ученик видит материал блока над своей группой вопросов — в обеих частях и в обоих режимах ответа. Блок без привязок = материал над всей Частью 1.
- **AC-9.** Транскрипт блока раскрывается только post-submit; под student JWT `select('block_transcripts_json')` → permission denied.
- **AC-10.** Сохранение из устаревшей вкладки → 409 `VARIANT_STALE`, не тихая перезапись.
- **AC-11.** Дубликат своего варианта сохраняет треки; дубликат каталожного честно сообщает, сколько записей не скопировалось.

### Ревью

ChatGPT-5.6, вердикт **NOT APPROVED**: 5×P0, 7×P1, 1×P2. Все закрыты (`407b2df`, `5700e42`). Полный разбор с причинами — skill `mock-exams`, раздел «Блоки заданий». Промпт ревью — `review-prompt-blocks.md`.

Два места, где формулировка ревьюера сознательно сужена: пустой несвязанный блок удаляется без подтверждения (подтверждать нечего); несмежные привязки **предупреждают, но не блокируют** сохранение — сценарий законный, репетитору нужно знать последствие, а не запрет.

### Порядок деплоя (обязателен)

Три миграции по возрастанию → три edge (`tutor`/`student`/`public`) → **фронт последним** (`deploy-sokratai`). Проверка после миграций: `block_transcripts_json` и `listening_transcript` ОТСУТСТВУЮТ в гранте `authenticated`.
