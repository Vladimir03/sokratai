## Баги и запросы репетиторов (приёмочные критерии — проверять КАЖДЫЙ по коду)

1. **Егор: «нет кнопки Раздать зоны» на доске без занятия** (создал новую доску — кнопки нет). Было: кнопка рендерилась только при `board.lesson_id`. Должно стать: кнопка ВСЕГДА видна (`src/pages/tutor/Whiteboard.tsx`); на доске занятия — авто-раздача по группе (как раньше), иначе — диалог-пикер учеников → `distributeZones(boardId, student_ids)`. Проверь: серверная валидация `student_ids` в `whiteboard-api::handleDistributeZones` (принадлежность `tutor_students.tutor_id = tutorPkId`, `archived_at IS NULL`, fail-closed на чужой id, кап 30), идемпотентность повторной раздачи сохранена.
2. **Егор/ученики: «ученики ждут зону, не знаю, как им выдать»** (баннер «писать можно будет, когда репетитор выдаст вам зону»). Должно стать: (а) пикер из п.1; (б) селект «чей лист» в тулбаре (`BoardToolbar.sheetOwner`) — назначение зоны СУЩЕСТВУЮЩЕМУ листу через zone-patch `saveBoardPage`; (в) `whiteboard-public::listCandidates` включает владельцев зон — гость видит себя в списке «я — Маша» и на доске без занятия.
3. **Елена: «Зашли с учеником на доску — не увидели друг друга»**. Корень: ученики заходят ГОСТЯМИ по /b/-ссылке, гости не в live-presence (нет JWT). Должно стать: панель «На доске:» видна ВСЕГДА; гости приходят поллингом `GET /boards/:id/guests` (tutor-only, активность по `last_seen_at` ≤ 40 c; `/signals` гостя обновляет метку). Проверь: роут не отдаёт лишних полей (guest_token НЕ должен утекать в ответ!), поллинг останавливается при unmount и скрытой вкладке, гость-чип не даёт follow.
4. **Елена: «не могу уменьшить решение и спихнуть в угол» + Вадим: «менять размер нарисованного»**. Должно стать: угловые ручки на рамке выделения → пропорциональный масштаб ЛЮБЫХ выделенных элементов. Проверь: `model.ts::scaleElement` (кламп фактора [0.05,20], нижний кламп bbox ~2 мм, толщина пера/размер текста клампятся, `bumpVersion` ОБЯЗАТЕЛЕН — иначе LWW-reconcile отдаст элемент удалённой стороне); превью через SVG-transform без пересчёта до pointerup (перфоманс!); у одиночной картинки остаются её ручки с поворотом — нет двойных ручек; жест не конфликтует с move/marquee/ghost-tap.
5. **Вадим: «изменить цвет уже нарисованного»**. Клик по свотчу при активном выделении перекрашивает выделенное (кроме картинок) через `bumpVersion` и меняет текущий цвет — обе поверхности (тутор + SharedBoardView).
6. **Ульяна: «ладошки нет — двигать лист»**. Инструмент `pan` в обоих тулбарах: пан из любой точки, НЕ создаёт листы (ветка до ghost-ячеек), курсор grab.
7. **Гость-зритель заперт** (вошёл до раздачи зон → навсегда read-only). Кнопка «Сменить имя» в шапке гостя: сброс guest_token → join-экран со СВЕЖИМ списком кандидатов.

## Что проверять сверх приёмки (в порядке приоритета)

1. **Безопасность**: guests-роут и zones-пикер — ownership fail-closed; zone-ветка `is_board_participant` не расширяет доступ сверх задуманного; в ответах нет bearer'ов (guest_token, slug) и tutor-only полей.
2. **Гонки/синк**: назначение «чей лист» бампит rev (ученики видят сразу); масштаб/перекраска идут через bumpVersion (LWW); scale-жест на фоне входящего remote-merge (protectedIds по выделению — уже есть, проверь что scale его не обходит).
3. **Перфоманс**: превью масштаба — transform, не пересчёт; поллинг гостей 10 с не дёргает лишних ре-рендеров; memo-цепочка FrameLayer не сломана новыми пропсами.
4. **Cross-browser (rule 80)**: Safari 15/iOS 15 — без lookbehind/structuredClone/Array.at/Object.hasOwn/crypto.randomUUID в новом коде; чекбоксы/селекты ≥16px; touch-action на кнопках.
5. **Контракты**: rule 97 (non-2xx = JSON с русской фразой), rule 60 (FK-дрейф tutor_id), идемпотентность миграции.
