## Промпт №1 — Фаза 1, сквозная цепочка (goal-режим)

```
ЦЕЛЬ. Репетитор проводит урок на встроенной доске, ничего специально не нажимает
по окончании — и конспект в виде PDF сам оказывается в материалах занятия, где его
открывает ученик. Это приёмочный критерий: пока он не выполняется, задача не решена,
сколько бы инструментов рисования ни было готово.

КОНТЕКСТ. Читай в таком порядке, не пропуская:
  1. docs/delivery/features/whiteboard/spec.md — полная спека с обоснованиями
  2. docs/delivery/features/whiteboard/tasks.md — задачи W1.1–W1.12
  3. AGENTS.md и .claude/rules/98-schedule-materials.md — как устроены материалы занятия

ЧТО СТРОИМ (Фаза 1, задачи W1.1–W1.12):

Данные. Три новые таблицы: boards, board_pages, board_sessions (схема в spec §5).
Только аддитивно. tutor_lessons НЕ ТРОГАТЬ — high-risk файл (rule 10).
RLS: репетитор видит свои доски; ученик — только доски занятий, где он участник,
и только через SECURITY DEFINER-хелперы (прямой JOIN в USING() даёт false-negative
на промежуточных таблицах, см. rule 98).

Бэкенд. Edge-функция whiteboard-api, verify_jwt=true, CRUD досок и страниц.
Каждый non-2xx — JSON {error, code} с русской фразой (rule 97). Клиент разбирает
через extractEdgeFunctionError.

Холст. Страница = ОТДЕЛЬНАЯ СЦЕНА: свой массив elements + свой appState,
переключение через updateScene. НЕ фреймы на общем холсте — иначе не будет
навигации и предсказуемого экспорта. Панель страниц внизу слева: миниатюры,
кнопка +, удаление (модель Meleto).

Разлиновка на уровне страницы: чистый / клетка / линейка / точка, шаг 5 и 10 мм.

Экспорт. exportToSvg → svg2pdf.js → jsPDF, страница = лист PDF. Все три под MIT.
Масштаб печати выводится из grid_mm: при 5 мм на вертикальную A4 влезает
36 клеток — размер обычной ученической тетради.

ГЛАВНОЕ (W1.10). Готовый PDF прикрепляется к занятию через СУЩЕСТВУЮЩИЙ путь —
tutor_lesson_materials с kind:'pdf', тот же, которым уже грузятся конспекты.
Ученик увидит его в карточке занятия БЕЗ ЕДИНОЙ ПРАВКИ на своей стороне.
Не изобретай новую сущность для этого.

Вход. Кнопка «Доска» в диалоге занятия у репетитора.
⚠️ TutorSchedule.tsx — 5882 строки, high-risk (rule 10). Только добавление кнопки,
никаких рефакторингов рядом.

ЧТО НЕ ДЕЛАТЬ В ЭТОЙ ФАЗЕ:
  — формулы, вставку изображений, задачу из Банка знаний, передачу мела
  — совместное редактирование и WS-релей: в Фазе 1 доска однопользовательская
  — кубики, таймеры, шаблоны

ОБЯЗАТЕЛЬНЫЕ ИНВАРИАНТЫ:
  • React.lazy для страницы доски — Excalidraw ~2.3 МБ, в shared-компоненты не тянуть
  • Safari 15 baseline (rule 80): parseISO вместо new Date("…"), 100dvh вместо 100vh,
    16px на инпутах, никаких lookbehind / structuredClone / .at() / Object.hasOwn
  • supabase только из @/lib/supabaseClient (rule 96)
  • FK-дрейф: tutor_students.tutor_id → tutors.id (rule 60)

ПРОВЕРКА ПЕРЕД СДАЧЕЙ:
  npm run lint && npm run build && npm run smoke-check   (последовательно, не параллельно)
  git diff --staged | grep -E "supabase\.co"             (любое попадание кроме api.sokratai.ru — блокер)

СДАЧА. Опиши: (1) изменённые файлы, (2) какие команды прогнал и с каким результатом,
(3) что сознательно не трогал. Напомни, что миграции и edge-функции НЕ деплоятся
сами — нужна отдельная просьба агенту Lovable, а факт выкладки проверяется
curl -X OPTIONS. И что фронт требует deploy-sokratai.
```

## Промпт №2 — Фаза 2, дифференциаторы

Запускать **после** того, как приёмочный сценарий Фазы 1 прошёл вживую.

```
ЦЕЛЬ. Доска перестаёт быть «ещё одной доской» и становится той, которую выберут
из-за связи с платформой.

Задачи W2.1–W2.14 из docs/delivery/features/whiteboard/tasks.md.

Приоритет внутри фазы именно такой:

1. ВСТАВКА ИЗОБРАЖЕНИЯ + ПИСЬМО ПОВЕРХ (W2.1–W2.2). Это тир-1 фича, её называют
   почти все репетиторы дословно: «вырезаю задачи с РешуЕГЭ ножницами, вставляю
   на доску и поверх пишу стилусом». Переиспользуй usePasteImages (rule 40).

2. ЗАДАЧА ИЗ БАНКА ЗНАНИЙ НА ДОСКУ (W2.3). Того же не может ни одна чужая доска —
   у них нет вашего контента. Это и есть защитимая позиция.

3. ФОРМУЛЫ на MathLive (W2.4–W2.8). Механика копируется с Idroo, она фактически
   готовая спецификация:
     • / дробь, ^ степень, _ индекс, Enter новая строка внутри формулы
     • наведение на символ палитры показывает LaTeX-команду — палитра учит синтаксису
     • выравнивание по знакам равенства
     • частичная раскраска фрагмента — ради этого репетиторы Idroo и держат:
       можно подсветить ровно то, что изменилось в преобразовании
   ⚠️ Формула ОБЯЗАНА уметь отдавать свой SVG для экспорта, иначе она не попадёт
   в PDF — это самая частая причина «формулы поехали». Плюс растровый фолбэк 2–3× DPI.

4. ПЕРЕДАЧА МЕЛА (W2.9–W2.14). В каждый момент пишет ОДИН — одновременности нет,
   поэтому CRDT не нужен, хватает version/versionNonce самого Excalidraw.
   Мел по умолчанию у репетитора; он забирает его одним нажатием БЕЗ СПРОСА;
   уход ученика возвращает мел автоматически.
   ⚠️ Ink гнать через СВОЙ WebSocket-релей в Москве, НЕ через Supabase Realtime:
   там лимит 500 сообщений/сек на весь проект (одна рисующая пара даёт ~100),
   и US-регион добавляет 250–400 мс — для рисования это заметное «мыло».
```

## Промпт №3 — Фаза 3, качество ввода

```
ЦЕЛЬ. Довести ощущение до «почти как на бумаге» — именно по этому репетиторы
сравнивают доски между собой.

Задачи W3.1–W3.6.

Главная — W3.1: ОБЪЕДИНЕНИЕ БЛИЗКИХ ШТРИХОВ в один объект с настраиваемой
чувствительностью.

Зачем: в Excalidraw каждый штрих — отдельный элемент. Написал формулу от руки —
получил 30 объектов, которые нельзя выделить и передвинуть как одно целое.
У Meleto для этого есть отдельный алгоритм, и, судя по отзыву репетитора
(«не виснет», «приятный дизайн»), именно он даёт то ощущение, за которое эту
доску хвалят.

Остальное: отключаемая чувствительность к нажиму для Apple Pencil (#11322),
настройка агрессивности сглаживания (по умолчанию оно создаёт непреднамеренные
соединения элементов), ластик по частям объекта, блокировка объекта, лазерная указка.
```
