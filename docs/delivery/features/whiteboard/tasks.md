## Раунд 3 (2026-07-29): текст — настоящая причина, площадь листа, архитектура

- **Текст (третий заход, корень найден).** Textarea монтировался и фокусировался ВНУТРИ pointerdown, после чего браузер выполнял default-действие mousedown — уводил фокус на body → мгновенный blur → blur-коммит пустого значения закрывал поле в ту же миллисекунду. Фикс: `event.preventDefault()` на pointerdown холста (отменённый pointerdown подавляет compat-mousedown → фокус никто не крадёт) + детерминированный `blur()` активного редактируемого поля перед новым жестом. Прошлый id-гард остаётся — он закрывает вторую гонку (blur ↔ новый черновик).
- **Площадь листа** (запрос владельца): per-page **ориентация** — горизонтальный A4 даёт 267 мм ширины вместо 180 (+48%); хранится в `board_pages.app_state.orientation` (jsonb, БЕЗ миграции), экспорт собирает смешанные документы (лист = своя ориентация). Плюс **зум**: «Вписать» / по ширине (100%) / 50–300% шагом 25 — fit-width на ноутбуке сам по себе сильно увеличивает рабочую площадь. При смене ориентации с контентом за краем — предупреждение (контент не удаляется, но в PDF не попадёт). Многолистовые «высокие» страницы (N×A4 с нарезкой при экспорте) — сознательно отложено.
- **Архитектура:** сетевое сохранение вынесено в чистый класс `AutosaveQueue` (single-flight, дренаж до конца, возврат в очередь при ошибке, авторетрай — 7 юнит-тестов с fake timers), undo/redo — в `SceneHistory` (дедуп burst'ов, лимит, инвалидация redo — 5 тестов). `Whiteboard.tsx` стал оркестратором; геометрия листа — данные (`pageSizeMm(orientation)`), а не глобальные константы.

Итог: vitest 84/84 (+14), чанк доски 43 КБ (PDF-движок по-прежнему отдельно), smoke 24/24.

## Сквозные инварианты

- ⚠️ **Ink не через Supabase Realtime** — лимит 500 сообщений/сек на весь проект, одна пара даёт ~100/сек; плюс US-регион = 250–400 мс
- ⚠️ **`tutor_lessons` не трогать** — high-risk (rule 10), только новые таблицы
- ⚠️ **FK-дрейф:** `tutor_students.tutor_id → tutors.id`, `homework_tutor_assignments.tutor_id → auth.users.id` (rule 60)
- ⚠️ **Safari 15 baseline** (rule 80): `parseISO` вместо `new Date("…")`, `100dvh` вместо `100vh`, 16px на инпутах
- ⚠️ **Миграции и edge-функции НЕ автодеплоятся** — отдельная просьба агенту Lovable + проверка `curl -X OPTIONS`
- ⚠️ **Фронт не доезжает до прода сам** — после правок в `src/**` нужен `deploy-sokratai` (rule 95)
- 🔴 **tldraw использовать нельзя** — проприетарная лицензия, прод запрещён без ключа (~$6 000/год)
- 🔴 **Excalidraw использовать нельзя** — NO-GO гейта 2026-07-29: незащищённый lookbehind в mermaid-хвосте (Safari/iOS ≤ 16.3) + 7,79 МБ хвоста + красный smoke-check §1. Детали — spec §3 Р4
- ⚠️ **mathlive — только с полифиллами** `Array.prototype.at` / `Object.hasOwn` / `structuredClone` в `main.tsx` до ленивых чанков, тем же PR (spec §7)
