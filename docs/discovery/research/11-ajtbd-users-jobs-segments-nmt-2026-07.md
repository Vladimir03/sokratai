## §1. Пользователи: треугольник B2B2C + четвёртая роль

| Роль | Позиция в сделке | Приоритет для продукта | Ключевое отличие по сегментам |
|---|---|---|---|
| **Репетитор** | Покупатель Сократа (сам платит 200–5000 ₽/мес) + профессиональный пользователь + ЛВР для семьи | **№1** | У языковиков клиент — взрослый ученик; у школьников — родитель |
| **Ученик** | Пользователь №1 по времени в продукте; у взрослых языковиков — ещё и плательщик своему репетитору | **№2** | Школьник 14–18 (ЕГЭ/ОГЭ) vs взрослый «для себя» (80% у Эмилии) |
| **Родитель** | ЛПР и плательщик репетитору (школьники); прямой пользователь только отчётов | №3 | У взрослых учеников роли нет |
| **Куратор / руководитель школы** | Новая роль (кастдев Эмилии, май; подтверждена 24.07): администрирует преподавателей, онбордит, контролирует качество, консолидирует расходы | №1-бис — это канал ×N | Один ЛПР = 13–20 преподавателей = 120+ учеников |

Деньги в цепочке: родитель/взрослый ученик → репетитор → Сократ. Сократ монетизируется через репетитора (и руководителя школы), поэтому value-гипотезы для ученика и родителя оцениваются по тому, как они усиливают удержание/готовность платить репетитора (retention-петля: ученику полезно → репетитор видит → продлевает → рекомендует).

### 2.1 Репетитор

**Big Jobs (мотивационный контекст, по сегментам):**
- Предметник-одиночка: «Разорвать линейную связь "доход = часы": больше учеников и выше ставка без потери качества и без вечеров за проверкой» (B2B-1/2, канон).
- Руководитель школы: «Масштабировать школу с единым стандартом качества, унифицировав зоопарк сервисов — "на одной платформе всё оформляешь и всё" — без роста расходов» (Эмилия, 10.07: сервисы ≈ 3% оборота 680 т.р./мес).
- Языковик: «Быть репетитором-методистом, чей ученик сдаёт международный экзамен, при том что рынок маленький и "у языковиков мало денег, но упороты все в эффективность и методику"» (Эмилия, 10.07).

**Core Job проверки (канон R1, переформулирован по данным двух созвонов — подтверждён Эмилией дословно 24.07):**

**⭐ Новый Core Job Т-СР «Самостоятельная работа» (ядро-инсайт этой волны).** Чат лидеров 24.07 (Елена, таблица «Виды работ»; Ульяна: «Очень здорово. Поддерживаю! Этого должно хватить») и Эмилия независимо (10.07: «наклепать 20 заданий… чтобы без чата») сформулировали одну и ту же Job:

Спектр AI-участия (= sub-jobs, каждый со своей метрикой успеха):

| Вид работы | AI для ученика | Job репетитора | Оценка (из таблицы Елены + правка Егора) |
|---|---|---|---|
| **Домашка** | Подсказки, диалог, guided-чат | Тренировать с наставником | % верного + **% самостоятельности** (сколько сделал без подсказок) |

## §4. КПР — критические последовательности работ

Формат канона: цепочка на оси времени, отмечены разрывы (⛔), циклы (↻), hand-off'ы (⇄), Aha (✨). Ценность цепочки = P(дойдёт до конца) × Outcome − Cost; чиним самое левое сломанное звено.

### 4.1 С1: недельная петля «урок → самостоятельная работа → фидбэк → родитель»

```
Репетитор: провёл урок
 → собрал работу (ДЗ/самостоятельная/пробник) за ≤10 мин   [✅ конструктор+AI-загрузка+банк]
 → назначил к занятию и отправил                            [✅; связь с занятием — есть (lesson materials)]
 ⇄ Ученик: узнал → открыл                                   [⛔ РАЗРЫВ №1 — TOC-горло: «не заходят/не разобрались» (3/3 кастдева, легенда xlsx); лечится онбордингом/PWA/кодом входа — в работе]
 → решает (с AI / без AI по виду работы)                    [⛔ РАЗРЫВ №2: режима «без AI» вне пробника НЕТ — Job Т-СР не исполняется]
 → сдал → AI-черновик проверки за 30 сек                    [✅ ядро; ⛔ РАЗРЫВ №3 для не-топ-предметов: карты режимов/баллов только физика+общество]
 ✨ Aha ученика: разбор по критериям НА ЕГО работе           [«супермотивирующе» — уже есть, усилить привязкой к местам работы]
 ⇄ Репетитор: подтвердил/поправил балл                      [✅ tutor review; ⛔ per-criterion правка отложена]
 ✨ Aha репетитора: «проверка заняла 2 минуты, не вечер»
```
